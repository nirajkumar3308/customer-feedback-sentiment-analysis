# Customer Feedback Sentiment Analysis System

## Overview
This project is a Python application to collect, store, and analyze customer feedback. It performs sentiment analysis and generates insights using Pandas and NumPy.

## Features
- OOP Design
- CSV Storage
- Sentiment Analysis
- Data Analysis using Pandas
- NumPy Statistics
- Unit Testing

## How to Run
pip install pandas numpy  
python main.py

## Output
- Sentiment Prediction
- Customer Satisfaction Score
- Product Ratings
